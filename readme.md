# BashMacDuler

BashMacDuler — приложение строки меню macOS для запуска Bash-скриптов по расписанию.

## Возможности

- добавление нескольких скриптов и ручной запуск;
- ежедневное, еженедельное и ежемесячное расписание по локальному времени;
- выбор одного или нескольких дней месяца для ежемесячного запуска;
- одноразовые запуски в выбранные календарные даты;
- запуск через `/bin/bash`, без необходимости делать файл исполняемым;
- параллельный запуск разных заданий и защита от повторного запуска одного задания;
- системные уведомления и логи stdout/stderr;
- сохранение расписаний и результатов между запусками приложения.

В ежемесячном расписании можно выбрать несколько чисел. Если выбранного числа нет в месяце (например, 31 февраля), этот месяц пропускается. В режиме выбранных дат каждый запуск одноразовый: после запуска удаляются прошедшие даты. Если компьютер или приложение были недоступны, выполняется не более одного пропущенного запуска.

Задания выполняются, пока BashMacDuler запущен. Закрытие окна оставляет приложение в строке меню; выход выполняется кнопкой «Выйти».

## Требования

- macOS 12 или новее;
- Xcode Command Line Tools (компилятор Swift и SDK macOS);
- для сборки иконки используются системные утилиты `sips` и `iconutil`.

Установить Command Line Tools, если они ещё не установлены:

```bash
xcode-select --install
```

Сторонние Swift-зависимости и Xcode-проект не требуются.

## Сборка

Откройте Terminal, перейдите в корень проекта (там, где находятся `build.sh` и `icon.png`) и соберите приложение:

```bash
cd /путь/к/BashMacDuler
./build.sh
```

Скрипт компилирует исходники из `Sources/`, преобразует `icon.png` в `BashMacDuler.icns`, создаёт и проверяет подпись app bundle. Результат:

```text
build/BashMacDuler.app
```

Запустить собранную копию без установки:

```bash
open build/BashMacDuler.app
```

Сборка использует ad-hoc подпись для локального запуска; это не Developer ID-подпись и не нотариализация для распространения вне локальной среды.

## Тесты

Запустите обе тестовые группы из корня проекта:

```bash
./test.sh
```

Проверяются вычисление расписаний (включая переходы летнего времени, выбранные дни месяца и календарные даты), обратная совместимость JSON и выполнение скриптов с логированием.

## Установка

Установка по умолчанию выполняется в `/Applications/BashMacDuler.app` и после установки открывает приложение:

```bash
./install.sh
```

Для этого у текущего пользователя должны быть права записи в `/Applications`. Установщик самостоятельно не запрашивает пароль администратора. Если прав нет, можно установить приложение в каталог пользователя:

```bash
mkdir -p "$HOME/Applications"
BASHMACDULER_INSTALL_PATH="$HOME/Applications/BashMacDuler.app" ./install.sh
```

Можно также дважды щёлкнуть `Install.command` в Finder. Он запускает тот же установщик.

Переменные установщика:

- `BASHMACDULER_INSTALL_PATH` — полный путь к app bundle; родительский каталог должен уже существовать, имя назначения — `BashMacDuler.app`.
- `BASHMACDULER_SKIP_OPEN=1` — установить приложение, не открывая его после установки.

Старые имена переменных `SCRIPTBAR_INSTALL_PATH` и `SCRIPTBAR_SKIP_OPEN` оставлены для совместимости. Перед заменой установщик проверяет целевой путь и bundle identifier; он заменяет только приложение BashMacDuler с совпадающим идентификатором и отказывает для произвольных файлов, символических ссылок и каталогов. Для повторной установки используйте `./install.sh`. Не запускайте установщик для проверки сборки — используйте `./build.sh`.

## Данные и логи

Для сохранения существующих настроек после переименования приложения каталог данных оставлен прежним:

```text
~/Library/Application Support/ScriptBar/scripts.json
~/Library/Application Support/ScriptBar/Logs
```

Если настройки не удаётся прочитать, BashMacDuler оставляет исходный файл без изменений и блокирует запись до устранения ошибки. Ошибки сохранения показываются в интерфейсе. При запуске приложения удаляются обычные `.log`-файлы старше 30 дней, кроме файлов, на которые ссылается последний запуск задания.
